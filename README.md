# Home Base

A daily-life app for health, training and money, shared between two people.

- `ios/`: the iPhone app (SwiftUI, live Apple Health). See `ios/README.md` to run it.
- `web/`: the browser version, a single HTML file. `home-base.html` is the built page; edit the source files and run `python3 merge.py`. AI features live here only, not in the iPhone app.

Data stays on the device. Garmin and MacroFactor reach Home Base through Apple Health.
